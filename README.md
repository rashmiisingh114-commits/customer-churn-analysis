# Customer Churn Analysis
An end-to-end Customer Churn Analysis project using **Python, SQL, Pandas, Matplotlib, and Seaborn** to identify churn patterns, analyze customer behavior, and generate actionable business insights.

## Objectives
- Clean and transform raw customer data
- Perform feature engineering
- Analyze churn using key business KPIs
- Visualize customer behavior
- Generate business recommendations

## Tech Stack
- Python
- Pandas
- NumPy
- SQLite
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The project uses three relational datasets:
- **customer.csv** – Customer demographics
- **subscription.csv** – Subscription & billing details
- **support.csv** – Customer complaints and CSAT

## Feature Engineering
Created the following business features:
- Churn Flag
- Customer Tenure
- Customer Age
- Complaint Count
- Churn Risk (Low / Medium / High)

## KPIs
- Churn & Retention Rate
- ARPU
- Revenue at Risk
- Customer Tenure
- Churn by Plan, State & Subscription Type
- Escalation Rate
- Average Complaints per Customer

## Key Insights
- Churn Rate: **28.6%**
- Monthly contracts have significantly higher churn than annual contracts.
- Basic Plan customers show the highest churn.
- Karnataka recorded the highest churn.
- Approximately **18%** of monthly recurring revenue is associated with churned customers.
